---
name: Open Round Robin has a distribution rule that Round Robin does not
 description: ORR uses a specific distribution/rotation rule that is absent from normal Round Robin; this is a core functional difference alongside the Time to Lead column
type: feature
---

Open Round Robin is not just normal Round Robin plus a timer. It adds a distribution rule that decides which eligible available salesperson receives each lead.

**Rule:**
- Normal Round Robin follows the existing rotation/cap rules already used in the CRM.
- Open Round Robin uses its own distribution rule: it prioritises the agent furthest behind, then longest-waiting, then caps-page order, while respecting on/off shift, breaks, leave and daily caps.
- This distribution rule is a structural difference between the two systems, separate from the extra Time to Lead column.

When ORR is live for a team, that team’s leads route through the ORR distribution rule. Other teams continue using the normal Round Robin rule.
