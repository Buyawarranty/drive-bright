---
name: Late-start agents rejoin at back — overnight batch is forfeit
description: An agent who starts late (e.g. 10am not 9am) gets none of the 09:00 overnight release; they rejoin the back of the rotation with no catch-up
type: feature
---
Lead rotation NEVER catches an agent up: new starters, holiday returns and late starts rejoin at the back and take normal turns. Never order by assigned_today.

Overnight/09:00 rule (agreed 30 Aug 2026): the 09:00 overnight batch is shared ONLY between agents switched on at release time. A late starter gets none of that batch, ever — the leads belong to the pool, not the agent, so nothing is owed and nobody's allocation is redone. From switch-on they take normal turns from leads still waiting plus new arrivals.

Rehearsal path in the ORR sandbox: run the 09:00 release with one agent switched off, then switch them on and watch later leads flow to them in turn.
