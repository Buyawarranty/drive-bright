---
name: Open Round Robin New Leads section shows ORR and RR leads together
 description: The ORR-enabled New Leads view is a single merged list containing both Open Round Robin and normal Round Robin lead rows
type: feature
---

When Open Round Robin is live for a team, the New Leads section for those agents is a single merged flow. Both ORR leads and normal Round Robin leads appear in the same list, row by row.

**Rule:**
- Agents do not switch between two separate pages or tabs to see ORR leads versus RR leads.
- The same table contains both types, distinguished by the **Time to Lead** column and an identifying tag (e.g. "Open Round Robin" vs "Round robin").
- ORR rows show the reservation countdown in Time to Lead; RR rows show "No time limit — stays with this agent".
- The countdown belongs to the lead, not the agent: a lead keeps whichever system it arrived under, regardless of which agent later views it.
- Column order and the rest of the table stay identical to the normal Round Robin view.

This merged view applies to the live New Leads page once ORR is enabled for a team, and to the sandbox practice view when testing mixed flows.
