## Working Week Rota (weekly Mon–Sun)

- All days start **unticked** by default.
- First click toggles a day on as a **full day**.
- Half-day toggle is secondary and only available once a day is on.
- **Saturday must be confirmed** if the agent is working; otherwise managers assume no Saturday cover.
- **Sunday is optional** — confirm only if working.
- Default view is the current week, with buttons to switch to next week.

## Weekend Shifts (monthly)

- Rendered below the Working Week Rota on the Timesheets tab.
- Agents must pick **at least 2 Saturday AM shifts (9am–1pm)** per month.
- Sundays are optional (AM/PM slots).
- Managers can edit anyone's picks; agents can only edit their own.
