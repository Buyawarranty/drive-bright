## Working Week Rota click defaults

- Weekdays (Mon–Fri): first click toggles a day on as **full_day**.
- Saturday and Sunday: first click toggles a day on as **half_day**.
- Agents can still switch any day to **Full**, **Half**, or **Off** via the per-day buttons.
- Weekends must still be confirmed (working or off) so managers can allocate leads.
