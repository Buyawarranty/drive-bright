---
name: Name boxes take letters only
description: Customer name boxes strip digits and stray symbols as you type, so a first name can never be "222"; phone boxes do the opposite and strip letters
type: preference
---

Every customer name box on the site (Step 2, Review & Pay, multi-warranty checkout, contact details, warranty transfer) only ever takes letters. Digits and stray symbols are stripped as the person types, so a first name can never end up as "222" and never gets a green tick for it.

This mirrors the mobile box, which only ever takes digits — the two rules are the same idea pointed the other way. Apostrophes, hyphens, full stops and spaces stay in, so O'Brien, Smith-Jones, Renée and J. R. Smith still type normally.

The rule is one shared check used by the forms, their tests and the submission function, so they can never disagree. An empty box stays quiet until the button is pressed.
